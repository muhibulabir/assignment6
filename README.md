Project Name- FitLog

FitLog is a dark, modern workout library app built with Next.js. It lets users browse exercise cards, add lifts to a daily plan, save workouts for later, and track a simple plan summary in a clean gym-focused interface.

## Technologies Used

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- DaisyUI

## Key Features

1. Responsive workout library grid with sorting
2. Detailed workout pages with instructions and spec cards
3. Daily plan and saved-items tracking using localStorage
4. Toast notifications for user actions
5. Loading and 404 states
